ЖАНР: 2D Платформер
  Персонаж бегает, прыгает по платформам, собирает монеты.
  Есть анимации (idle, run, jump, fall), тайловая карта уровня,
  главное меню, экран настроек (громкость, управление, разрешение).

--------------------------------------------------
ОПИСАНИЕ КАЖДОГО ФАЙЛА
--------------------------------------------------

[ main.py ]
  Точка входа. Инициализирует pygame, создаёт объект Game и
  запускает главный цикл. Никакой логики кроме старта.

--------------------------------------------------

[ src/settings.py ]
  Все константы проекта в одном месте:
  - Разрешение окна (WIDTH, HEIGHT)
  - FPS
  - Гравитация, скорость персонажа, высота прыжка
  - Пути к ресурсам (ASSETS_DIR, FONTS_DIR, ...)
  - Цвета (WHITE, BLACK, ...)
  - Настройки анимаций (кол-во кадров, скорость)
  - Дефолтные настройки (громкость, управление)

--------------------------------------------------

[ src/game.py ]
  Главный класс Game — управляет жизненным циклом приложения:
  - Инициализация pygame, окна, clock
  - Стек состояний (State Stack): хранит текущее состояние
    (меню / игра / настройки) и переключает между ними
  - Главный цикл: handle_events → update → draw
  - Загрузка и кэширование ресурсов (изображений, звуков)
  - Хранение глобальных настроек (громкость, клавиши)

--------------------------------------------------

[ src/states/base_state.py ]
  Абстрактный базовый класс для всех состояний:
  - Методы handle_events(events), update(dt), draw(screen)
  - Ссылка на объект Game для переключения состояний
  - Метод on_enter() и on_exit() — вызываются при входе/выходе

[ src/states/menu_state.py ]
  Главное меню игры:
  - Отрисовка фона с параллакс-эффектом
  - Кнопки: "Играть", "Настройки", "Выход"
  - Анимированный логотип / заголовок
  - При нажатии кнопок — переключение состояний через Game

[ src/states/settings_state.py ]
  Экран настроек:
  - Слайдер громкости музыки
  - Слайдер громкости звуков
  - Выбор разрешения (переключение вариантов)
  - Переназначение клавиш (нажать кнопку → нажать новую клавишу)
  - Кнопка "Назад" — возврат в меню
  - Сохранение настроек в словарь Game

[ src/states/game_state.py ]
  Состояние геймплея:
  - Создание игровых объектов (Player, Platform, Coin)
  - Группы спрайтов pygame (all_sprites, platforms, coins)
  - Загрузка уровня из данных (списка тайлов)
  - Обработка ввода с клавиатуры → передача в Player
  - Вызов update(dt) для всех спрайтов
  - Работа с Camera: сдвиг экрана за персонажем
  - HUD: счёт монет, жизни
  - Проверка условия победы/поражения

--------------------------------------------------

[ src/entities/player.py ]
  Класс Player (наследует pygame.sprite.Sprite):
  - Загрузка спрайт-листа через SpriteSheet
  - Словарь анимаций: {"idle": [...], "run": [...],
    "jump": [...], "fall": [...]}
  - Компонент Animation для смены кадров
  - Физика: скорость, гравитация, обнаружение столкновений
    с платформами (по оси Y отдельно от X)
  - Метод handle_input(keys) — движение влево/вправо, прыжок
  - Flip изображения при смене направления

[ src/entities/platform.py ]
  Класс Platform (наследует pygame.sprite.Sprite):
  - Загрузка тайла из тайлсета по индексу
  - Статичный спрайт, только rect для коллизий

[ src/entities/coin.py ]
  Класс Coin (наследует pygame.sprite.Sprite):
  - Анимированная монета (спрайт-лист с вращением)
  - При коллизии с игроком — исчезает, +1 к счёту

--------------------------------------------------

[ src/ui/button.py ]
  Класс Button:
  - Два изображения: нормальное и при наведении
  - Метод handle_event(event) → возвращает True при клике
  - Метод draw(screen)
  - Поддержка текста поверх кнопки

[ src/ui/slider.py ]
  Класс Slider:
  - Трек и бегунок (отрисовка через pygame.draw или картинки)
  - Диапазон значений (min, max), текущее значение
  - Перетаскивание мышью
  - Метод get_value() → float

--------------------------------------------------

[ src/utils/spritesheet.py ]
  Класс SpriteSheet:
  - Загружает PNG с несколькими кадрами
  - Метод get_image(x, y, width, height) → Surface
  - Метод get_strip(row, count, frame_w, frame_h) → list[Surface]
  - Поддержка colorkey для прозрачности

[ src/utils/animation.py ]
  Класс Animation:
  - Список кадров (Surface), скорость (frame_duration)
  - Метод update(dt) — переключает кадры по времени
  - Метод get_current_frame() → Surface
  - Флаг loop (зациклить или остановиться на последнем кадре)

[ src/utils/camera.py ]
  Класс Camera:
  - Хранит смещение (offset_x, offset_y)
  - Метод update(target) — следит за персонажем,
    плавно центрирует его на экране
  - Метод apply(sprite) → rect со смещением для отрисовки
  - Ограничение камеры по краям уровня
